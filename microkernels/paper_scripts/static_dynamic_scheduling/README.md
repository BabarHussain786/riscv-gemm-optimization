# Static and Dynamic Scheduling

This folder contains the launchers for the paper's scheduling comparison:

- `run_fig03_static_vs_dynamic.sh` runs the Figure 3 campaign through the
  common paper runner.
- `run_k1_static_dynamic_scheduling.sh` runs the SpaceMiT K1 partitioning and
  scheduling analysis.

The wrappers preserve the original project paths and can be launched from any
working directory. Results are written to the configured benchmark output
directory; this folder contains scripts only.
